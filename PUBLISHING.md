## Publish on GitHub

1. Create a new public GitHub repository named `victor-kao-academic-portfolio`.
2. Upload the contents of this folder—not the folder itself—so that `README.md` is at the repository root.
3. In the repository’s **About** panel, add the description, topics, and the LinkedIn link from the metadata suggestions above.
4. Confirm that the two images render in the README and that the MAILO and LinkedIn links open correctly.
5. Review the repository once more for privacy: do not add unpublished notes, thesis drafts, private application materials, or personal contact details.

## Positioning for applications

Use this repository as a short public landing page alongside the formal application package. Keep the README as the canonical version; no GitHub Pages site is necessary for this focused academic portfolio.
